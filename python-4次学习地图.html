Python 四次学习地图

每讲约 2.5 小时主体学习 + 1 小时动手练习 · 四次之后能独立完成一份小型数据分析

核心思路：第 1、2 次解决"能写"，第 3 次解决"能存、能复用"，第 4 次解决"能用来干活"。所以前两次不要纠结写得多优雅，先把程序跑通；第 4 次不要贪多，把一个新数据集从读入到出图跑完整一遍就够。

四次主线一览

次数主题动手产出
第 1 次语法地基猜数字小游戏
第 2 次数据结构与函数通讯录管理程序
第 3 次模块、文件与面向对象能存盘的记事本

1

语法地基：让程序能跑起来

目标：看懂一段 30 行的 Python 代码在干什么，并能自己改动它。
要掌握的知识点
  • 变量与类型：int / float / str / bool，用 type() 自查
  • 输入输出：print()、input()（记住它返回的永远是字符串，要算数得先 int()）
  • 条件判断：if / elif / else，比较运算符与布尔运算符
  • 循环：for 配 range()、while，以及 break / continue
  • 缩进就是语法：Python 靠缩进划分代码块，四个空格一层
代码骨架
import random

target = random.randint(1, 100)
count = 0

while True:
    guess = int(input("猜一个 1-100 的数："))
    count += 1
    if guess < target:
        print("小了")
    elif guess > target:
        print("大了")
    else:
        print(f"对了！你用了 {count} 次")
        break
动手练习
  1. 把上面的游戏改成"只给 7 次机会，用完就输"
  2. 写一个程序，问名字和年龄，输出"XXX 在 2030 年时是 XX 岁"
  3. 用 for 打印九九乘法表的前三行
通关标志：不查资料能独立写出带循环和判断的程序，知道 input() 的类型陷阱，报错时能看懂 SyntaxError 和 IndentationError 在说什么。
最容易卡住的点：把 = 和 == 混用；input() 没转 int 就直接比较；缩进用了 Tab 和空格混排。
2

装数据的容器与函数

目标：能用列表和字典组织一批数据，并把重复逻辑抽成函数。
要掌握的知识点
  • 列表 list：索引、切片、append / remove / sort、len()
  • 字典 dict：键值对、get() 取不存在的键不报错、遍历 .items()
  • 元组与集合：什么场景用它们（不可变、去重）
  • 列表推导式：[x*2 for x in nums if x > 0] 这一行要读懂
  • 函数：def、参数与默认值、return、作用域（函数里的变量外面看不到）
代码骨架
contacts = {}   # 名字 -> 电话

def add(name, phone):
    contacts[name] = phone
    return f"已添加 {name}"

def find(keyword):
    return {k: v for k, v in contacts.items() if keyword in k}

add("张三", "13800000000")
add("李四", "13900000000")
print(find("张"))
动手练习
  1. 给通讯录加上 delete() 和"列出全部"功能
  2. 给一个分数列表，用函数算出平均分、最高分、及格人数
  3. 把一份"姓名,成绩"的字符串列表转成字典，并按成绩排序输出
通关标志：看到一批数据，会先想"用列表还是字典装"；写出超过 10 行重复代码时会条件反射地想抽成函数。
最容易卡住的点：列表赋值 b = a 是同一个对象，改 b 会改 a（要用 a.copy()）；函数里 print 了却没 return，拿到的结果是 None。
3

模块、文件与面向对象

目标：写的程序能读写真实文件、能装第三方库、代码能分文件组织。
要掌握的知识点
  • 模块与包：import 三种写法、if __name__ == "__main__" 是干嘛的
  • 标准库：os / pathlib、json、datetime、random
  • 第三方库：pip install、虚拟环境为什么必须用
  • 文件读写：with open(...) as f 读写 txt / CSV / JSON，编码用 utf-8
  • 异常处理：try / except 让程序不因为一个坏输入就崩
  • 面向对象入门：class、__init__、self、属性与方法
代码骨架
import json

class Notebook:
    def __init__(self, path="notes.json"):
        self.path = path
        self.notes = self._load()

    def _load(self):
        try:
            with open(self.path, encoding="utf-8") as f:
                return json.load(f)
        except FileNotFoundError:
            return []

    def add(self, text):
        self.notes.append(text)
        with open(self.path, "w", encoding="utf-8") as f:
            json.dump(self.notes, f, ensure_ascii=False, indent=2)

if __name__ == "__main__":
    Notebook().add("今天学了文件读写")
动手练习
  1. 把第 2 次的通讯录改成读写 JSON 文件，关掉程序再打开数据还在
  2. 读一个 CSV 文件，统计行数、打印前 5 行
  3. 把 input() 输入非数字的情况用 try / except 处理掉
通关标志：能让数据在两个程序之间传递；能看懂 class 定义的代码；遇到 ModuleNotFoundError 知道是没装库或装错环境。
最容易卡住的点：忘了写 encoding="utf-8" 导致中文乱码；不用虚拟环境直接全局 pip install，装多了会互相冲突；self 忘了加。
4

数据分析实战收口

目标：拿一份真实的数据表，从读入、清洗、统计到出图，完整跑一遍。
要掌握的知识点
  • NumPy：数组跟列表的区别、向量化运算、mean / std
  • pandas 读数据：read_csv / read_excel、head() / info() / describe() 三件套
  • 筛选与排序：布尔索引、loc、sort_values
  • 分组统计：groupby().agg() —— 这是 pandas 最值钱的一招
  • 缺失值处理：isna().sum()、dropna() / fillna()
  • Matplotlib 出图：折线、柱状、散点，中文标题要设字体
代码骨架
import pandas as pd
import matplotlib.pyplot as plt

df = pd.read_csv("data.csv", encoding="utf-8")
print(df.info())
print(df.describe())

df = df.dropna(subset=["amount"])          # 清洗
df["日期"] = pd.to_datetime(df["日期"])     # 转换类型

by_month = df.groupby(df["日期"].dt.to_period("M"))["amount"].sum()
by_month.plot(kind="bar", title="每月销售额")
plt.tight_layout()
plt.savefig("monthly.png", dpi=150)
动手练习（这就是结课作业）
  1. 找一个自己感兴趣的数据集（公开数据平台上的 CSV 即可，几百行就够）
  2. 写一个小脚本完成：读入 → 看基本情况 → 处理缺失值 → 分组统计 → 画 2 张图
  3. 把结论写成 5 句话，配上图，就是一份数据分析小报告
通关标志：拿到陌生 CSV 能在 20 分钟内说出"这份数据有多少行、有哪些字段、最大值出现在哪、大致趋势是什么"。
最容易卡住的点：Matplotlib 中文显示成方框（需要指定中文字体）；把 pandas 的 SettingWithCopyWarning 当报错（其实只是提醒要用 .copy()）；一上来就想学机器学习，把基础统计跳过了。

四次之间怎么衔接

每次课前 15 分钟

不看资料，把上一次的产出代码重敲一遍核心部分。敲不出来说明上次没真会，先补。

每次课后当天

趁热把当次的 3 道练习做掉至少要 2 道。隔天再做的遗忘率明显更高。

三次之间不要跳

第 3 次的文件读写要用到第 2 次的字典，第 4 次的 groupby 依赖第 2 次的"分组"直觉。跳步会连崩。

统一用一个文件夹

建议 python-practice/day1 ... day4，每天的代码都留下来，后期就是自己的代码字典。

高频坑位速查

报错 / 现象原因与解法
IndentationError缩进不一致，全用 4 个空格，别混 Tab
TypeError: can only concatenate str字符串和数字相加了，用 int() 转换或 f-string
KeyError字典里没这个键，用 d.get(k) 更安全
IndexError索引越界，注意 Python 下标从 0 开始
ModuleNotFoundError没装库，或装到了别的 Python 环境里
UnicodeDecodeError文件编码不是 utf-8，open 时指定 encoding
Matplotlib 中文变方框需显式指定中文字体，如 SimHei
