Python 运算符

第 1 次课配套资料 · 属于「语法地基」模块 · 建议 60–90 分钟学完并做完练习

先搞清楚运算符是什么：变量是"装数据的盒子"，运算符就是"把盒子里的东西拿出来做加工的符号"。写代码本质上就两件事——存数据、加工数据。所以运算符学完，你写表达式的能力就定型了。

算术运算符：做数学

重点掌握 / 和 // 的区别，以及 % 取余的实际用途。
符号例子说明
+3 + 5 → 8加法；字符串也能用，"a"+"b" → "ab"
-3 - 5 → -2减法
*3 * 5 → 15乘法；"ab" * 3 → "ababab"（重复）
/7 / 2 → 3.5除法，结果永远是 float，哪怕能整除：4 / 2 → 2.0
//7 // 2 → 3整除，只保留整数部分（向下取整）
%7 % 3 → 1取余数，用来判断整除、奇偶
**2 ** 10 → 1024幂运算。注意没有 ^，^ 在 Python 里是位异或
为什么要区分 / 和 //

因为 Python 3 里 / 一律返回小数，这是为了避免"整数除法悄悄丢掉小数"的经典 bug。想要整数结果就得显式写 //，代码意图更清楚。

print(7 / 2)     # 3.5
print(7 // 2)    # 3
print(-7 // 2)   # -4  ← 注意！向下取整，不是 -3
print(7 % 3)     # 1
print(2 ** 10)   # 1024
print("ab" * 3)  # ababab
最容易踩的坑：-7 // 2 结果是 -4 而不是 -3。// 是"向下取整"（往数轴左边靠），不是"直接砍掉小数"。初学阶段用正数不会遇到，但心里要有数。
% 取余的经典用途
n = 17
print(n % 2 == 0)   # False → 判断偶数
print(n % 5 == 0)   # False → 判断能不能被 5 整除

seconds = 200
print(seconds // 60, "分", seconds % 60, "秒")   # 3 分 20 秒
2

比较运算符：比大小

结果一律是布尔值 True / False，是 if 判断和 while 循环的核心。
符号例子含义
==3 == 3 → True等于（两个等号）
!=3 != 5 → True不等于
> <5 > 3 → True大于 / 小于
>= <=3 >= 3 → True大于等于 / 小于等于
Python 特有的链式比较
x = 5
print(1 < x < 10)     # True，等价于 1 < x and x < 10
print(1 < 20 < 10)    # False

别的语言里要写成 1 < x && x < 10，Python 可以直接连着写，读起来跟数学式子一样。

头号错误：把 =（赋值）当成 ==（比较）用。if a = 1: 会直接报 SyntaxError。记住一句口诀：一个等号是"存进去"，两个等号是"比一比"。
3

赋值运算符：把结果存回去

掌握 += 这种简写，以及"Python 没有 ++"这个事实。
简写等价写法例子
a += 1a = a + 1计数、累加最常见
a -= 1a = a - 1倒计时
a *= 2a = a * 2翻倍
a /= 2a = a / 2注意结果变 float
a //= 2a = a // 2保持整数
a %= 10a = a % 10取个位
多重赋值（Python 的便利写法）
a, b = 3, 5          # 同时给两个变量赋值
a, b = b, a          # 一行交换两个变量的值，不需要临时变量
print(a, b)          # 5 3
Python 没有 ++ 和 --。如果你从 C/Java 转过来，a++ 会报 SyntaxError。请一律用 a += 1。（顺带一提，++a 不报错，因为它被解析成了"两次正号"，结果还是 a，这是个迷惑性很强的陷阱，别这么写。）
4

逻辑运算符：组合条件

理解 and / or 的"短路求值"，以及它们返回的不一定是布尔值这件事。
符号含义短路规则
and两边都为真才真左边为假，右边根本不执行
or一边为真就真左边为真，右边根本不执行
not取反—
关键机制：返回的是"操作数的值"，不是 True/False
print(3 and 5)      # 5    ← 左边为真，返回右边
print(0 and 5)      # 0    ← 左边为假，直接返回左边
print(0 or 7)       # 7    ← 左边为假，返回右边
print("" or "hi")   # hi   ← 空字符串算假
print(3 or 0)       # 3    ← 左边为真，直接返回左边

为什么这么设计？因为短路求值本来就要求"提前返回那个决定结果的值"，Python 干脆把它原样返回，而不是浪费一次转换。这个特性可以直接用来写默认值：

name = input("请输入名字：")
name = name or "匿名"      # 没输入就用默认值
print("你好，" + name)
什么是"假值"

除了 False，这些也当作假：0、0.0、""（空字符串）、[]（空列表）、{}（空字典）、None。其余基本都算真。

优先级：not > and > or。拿不准就加括号，括号永远是最清晰的解法：(a or b) and c。
5

成员运算符

in 判断元素是否在容器里，日常用得极多。

print("e" in "hello")   # True
print(3 in [1, 2, 3])   # True
print("a" not in "xyz") # True

d = {"name": "张三"}
print("name" in d)      # True ← 字典查的是"键"
坑：对字典用 in 检查的是键不是值。"张三" in d 是 False。
6

身份运算符

is 判断两个变量是不是同一个对象（内存地址相同），不是值相等。

a = [1, 2]
b = [1, 2]
print(a == b)   # True  值一样
print(a is b)   # False 两个不同的列表

m = int("1000")
n = int("1000")
print(m == n)   # True  值相等
print(m is n)   # False 两个不同的对象

x = None
print(x is None)      # True  ← 判空的标准写法
print(x is not None)  # False
坑：is 用于数字时结果不稳定——CPython 会缓存 -5~256 的小整数，同一段代码里相同的字面量也可能被复用（实测 1000 is 1000 为 True），但运行时生成的 int("1000") 却是 False。结论：比较值永远用 ==，只有跟 None 比才用 is。
7

位运算符 了解即可，初学可跳过

直接对整数的二进制位操作。做数据分析基本用不到，但在权限控制、压缩算法、底层优化里很常见。知道有这回事就行。

符号名称例子（5 = 101，3 = 011）
&按位与5 & 3 → 1（101 & 011 = 001）
|按位或5 | 3 → 7（111）
^按位异或5 ^ 3 → 6（110）
~按位取反~5 → -6
<<左移5 << 1 → 10（相当于 ×2）
>>右移5 >> 1 → 2（相当于 //2）
重申：^ 是位异或，不是幂运算。想算 2 的 10 次方写 2 ** 10，写 2 ^ 10 得到的是 8。

运算符优先级（从高到低）

不用背，但要知道大致顺序，以及"拿不准就加括号"这条铁律。

级别运算符说明
最高()括号，想改变顺序就用它
1**幂（注意是右结合：2**3**2 = 512）
2~ +x -x按位取反、正负号
3* / // %乘除类
4+ -加减
5<< >>移位
6&按位与
7^按位异或
8|按位或
9== != > < >= <= is in比较、身份、成员
10not逻辑非
11and逻辑与
12or逻辑或
最低= += -= ...赋值
一个容易错的顺序：比较运算符的优先级低于位运算符，但高于 not/and/or。所以 not a == b 其实是 not (a == b)，而不是 (not a) == b。加括号能省掉这类困惑。

五组易混辨析

① = vs ==

= 是"把右边存进左边"（赋值语句）；== 是"问两边是否相等"（比较表达式）。if a = 1 必报错。

② == vs is

== 比值，is 比身份（是不是同一个对象）。日常 99% 用 ==；唯一习惯用 is 的场景是判断 None。

③ / vs //

/ 得到小数（永远 float），// 得到整数商。算"几个人分几组""能装满几箱"用 //，剩下的用 %。

④ and/or 返回的是值，不是 True/False

3 and 5 得到 5，不是 True。这个设计让 x = x or 默认值 这种写法成立。如果确实要布尔结果，就写 bool(3 and 5)。

⑤ ^ vs **

^ 是位异或，** 才是幂。2 ** 10 = 1024，2 ^ 10 = 8。

练习 2：判断闰年（综合 % + and/or）

规则：能被 4 整除且不能被 100 整除，或者能被 400 整除。对 2024、1900、2000 分别验证。

参考答案（点开） 
def is_leap(year):
    return (year % 4 == 0 and year % 100 != 0) or (year % 400 == 0)

for y in (2024, 1900, 2000, 2023):
    print(y, is_leap(y))
# 2024 True
# 1900 False
# 2000 True
# 2023 False

练习 5：默认值写法（用 or 短路）
