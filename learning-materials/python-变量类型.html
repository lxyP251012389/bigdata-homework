Python 变量类型

第 2 次课配套资料 · 属于「语法地基」模块 · 建议 45–60 分钟学完并做完练习

先搞清楚"类型"是什么：程序里的数据不是一堆乱码，每一种数据都有自己的"物种"——数字能算加减，文字能拼接截取，列表能增删元素。这个物种就是类型。它决定了「这个值能做什么操作」。选错类型，程序要么报错，要么悄悄给出错误结果。

八种常用类型速览

类型写法示例装什么能改吗
int 整数18 -3不带小数点的数不可改
float 小数3.14 -0.5带小数点的数不可改
bool 布尔True False真 / 假，判断的结果不可改
str 字符串"你好" 'abc'一串文字不可改
list 列表[1, 2, 3]一组有序数据，可重复可改
tuple 元组(1, 2)一组有序数据，锁死不改不可改
dict 字典{"姓名": "小明"}一组「键 → 值」对应关系可改
set 集合{1, 2}一组无序数据，自动去重可改
另外还有个特殊的 NoneType，只有一个值 None，表示"什么都没有"。它不算在上面八种里，但几乎每个程序都会用到，后面单独讲。

图怎么看：先横向分两排——上排每个变量只存一个值，下排每个变量存一组值；再看颜色——蓝色系改不动，绿色系能原地改。注意两个"例外"位置：str 虽然是单个值但用法和容器很像（能切片、能遍历），tuple 虽然在容器排却不可改。这两处是最容易记混的地方。

逐个认识

1

数字：int 与 float

重点记住两件事：/ 永远得到 float；float 有精度误差。
类型例子说明
int18 -3 0整数。Python 的整数没有大小上限，10**100 照样算得动
float3.14 -0.5 2.0小数。只要有小数点或 / 运算，结果就是 float
 
print(7 / 2)      # 3.5   ← 除法永远得小数
print(7 // 2)     # 3     ← 整除才得整数
print(type(7/2))  # <class 'float'>
print(10 ** 100)  # 1 后面跟 100 个 0，不会溢出
精度坑：0.1 + 0.2 在 Python 里等于 0.30000000000000004，不等于 0.3。因为浮点数用二进制存储，很多十进制小数存不精确。比较小数不要用 ==，改成判断差值小于一个很小的数：abs(0.1+0.2 - 0.3) < 1e-9。涉及金额请改用「分」为单位存整数。
2

bool 布尔：只有两个值

记住首字母必须大写，以及哪些值会被当成「假」。

True 和 False，是判断表达式的结果。比较运算、in、and/or/not 算出来都是它。

print(3 > 5)          # False
print("a" in "abc")   # True
print(isinstance(True, int))  # True ← bool 其实是 int 的子类
print(True == 1)      # True    ← 所以 True 能当 1 用（但别这么写）
哪些值会被当成「假」

除了 False 本身，还有：0、0.0、""（空字符串）、[]（空列表）、{}（空字典）、None。其余都是「真」。注意 "0" 和 [0] 是真值——它们非空。

3

str 字符串：文字

牢记不可改——所有"改"字符串的操作，其实都是生成一个新的。
s = "hi"
print(s[0])        # h       按下标取字符，从 0 开始
print(s.upper())   # HI      生成新字符串
print(s)           # hi      原字符串没变！
print(len(s))      # 2
print("a" + "b")   # ab      拼接
print("ab" * 3)    # ababab  重复
最常见的误解：s[0] = "z" 会报 TypeError: 'str' object does not support item assignment。字符串和元组一样不可改。要改只能重新赋值：s = "z" + s[1:]。
4

list 与 tuple：一组有序数据

两者都能装一串东西，区别只有一个——能不能改。
对比list 列表 [1, 2]tuple 元组 (1, 2)
写法方括号 []圆括号 ()
能否修改能，append / pop / 下标赋值都行不能，改就报 TypeError
什么时候用数据会增删变化（成绩单、待办）数据不该变（坐标、配置、函数返回多个值）
性能稍占内存，改起来快更省内存，Python 处理更快
 
a = [1, 2]
a.append(3)     # 可以，a 变成 [1, 2, 3]
a[0] = 9        # 可以

b = (1, 2)
b[0] = 9        # TypeError: 'tuple' object does not support item assignment

x, y = (3, 4)   # 元组解包，一次性接住多个值，很常用
单元素元组要写逗号：(1) 是整数 1，(1,) 才是元组。这是初学者高频错误。
5

dict、set 与 None

dict 靠「键」查值，set 用来去重和判断存在，None 表示"没有"。

dict 字典

存「键 → 值」对，用键取值。d["姓名"] 得到 "小明"。键必须不可变（常用字符串），查起来比列表遍历快得多。

set 集合

无序、自动去重。set("aab") 得到 {"a", "b"}。最常用法：去重、判断在不在、求交集并集。

d = {"姓名": "小明", "年龄": 18}
print(d["姓名"])        # 小明
print(list(d.keys()))   # ['姓名', '年龄']  按插入顺序

nums = [1, 2, 2, 3]
print(set(nums))        # {1, 2, 3}  去重（打印顺序不固定）

result = None           # 占位：还没有结果
print(result == 0)      # False ← None 不等于 0
print(result == "")     # False ← 也不等于空字符串
print(bool(result))     # False ← 但它被当成「假」
None 怎么判断

永远用 is None / is not None，不要用 == None。因为 None 是全局唯一的一个对象（单例），is 判断的是"是不是同一个对象"，语义更准确。

两个必须懂的机制

A

动态类型：变量没有固定类型

Python 里"变量"本质上是个名字标签，贴在某个值上。类型属于值，不属于名字。所以同一个名字可以随时贴到不同类型的值上：

x = 18
print(type(x))   # <class 'int'>
x = "你好"
print(type(x))   # <class 'str'>   ← 同一个 x，类型变了
x = [1, 2]
print(type(x))   # <class 'list'>  ← 又变了，完全合法

这和 C / Java 不同——那些语言要先声明 int x;，之后 x 只能是整数。Python 不用声明，代价是类型错了不会在写代码时报错，要到运行到那一行才炸。所以不确定类型时随时 print(type(x))。

B

可变 vs 不可变

这是理解 Python 数据行为的分水岭：

  • 不可变：int float bool str tuple —— 想改只能造一个新值，原值不动
  • 可变：list dict set —— 能在原地增删，对象还是那一个
a = [1, 2]
b = a            # b 和 a 指向同一个列表，不是复制！
b.append(3)
print(a)         # [1, 2, 3]  ← a 也被改了

c = [1, 2]
d = c.copy()     # 真复制
d.append(3)
print(c)         # [1, 2]     ← c 不受影响
为什么重要：把列表传给函数时，函数里对它的修改会影响外面的原列表。这是最常见的隐蔽 bug 来源。不想被改就传 lst.copy() 或 list(lst)。

类型转换

不同类型之间可以互相转，用"类型名当函数用"：

写法例子结果
int(x)int("18") int(3.9)18 3（小数直接截断，不四舍五入）
float(x)float("3.5") float(7)3.5 7.0
str(x)str(18) str([1,2])"18" "[1, 2]"
bool(x)bool(0) bool("") bool([])全是 False
list(x)list("ab")['a', 'b']
set(x)set("aab"){'a', 'b'}（去重）
 
age = input("请输入年龄：")   # input 得到的永远是字符串！
print(type(age))              # <class 'str'>
age = int(age)                # 必须转成整数才能比较
print(age > 18)
最容易忘的一条：input() 返回的是字符串，直接拿去和数字比大小会报 TypeError。写作业时几乎一定会遇到。

五组易混辨析

① == 和 is 不是一回事

== 比的是值是否相等，is 比的是是不是同一个对象。

x = [1, 2]
y = [1, 2]
print(x == y)   # True   值一样
print(x is y)   # False  两个不同的列表对象

规则：比较值用 ==，只在判断 None 时用 is。补充：CPython 会缓存 -5 到 256 的小整数，所以 256 is 256 是 True，但这是实现细节，不要依赖它。

② "字符串不可改" 和 "变量能重新赋值" 不矛盾

s = "a"; s = "b" 能跑通，但改的不是字符串本身，而是把名字 s 从旧的 "a" 上撕下来贴到新的 "b" 上。变的是绑定关系，不是那个字符串对象。

③ None 不等于 0，也不等于空字符串

None == 0 是 False，None == "" 也是 False。但 bool(None) 是 False。语义上 None 是"没有值"，0 是"数值为零"，"" 是"空文本"，三件事。判空要分开写。

④ 什么时候用 list，什么时候用 tuple

要增删就用 list；数据定了就不该变，或者要当字典的键、放进集合，就用 tuple。因为字典的键和集合的元素都必须是不可变类型，list 放进去会报 TypeError: unhashable type。

⑤ 1 和 "1" 完全不同

1 + 1 得 2，"1" + "1" 得 "11"，而 1 + "1" 会报 TypeError。类型不同，+ 的含义就不同；Python 不会自动帮你把字符串转成数字。
