Python 流程控制

第 1 次课配套资料 · 属于「语法地基」模块 · 建议 45–60 分钟学完并做完练习

先搞清楚"流程控制"管什么：程序默认是从上往下、一行挨着一行执行的——这种"一条道走到黑"的执行方式，写不出真正的程序。流程控制就是给程序加上三种能力：会选（满足条件才走这条路）、会绕圈（同一段代码重复执行）、会中途改主意（提前跳出、跳过这一轮）。你 03.ipynb 里写的 for i in range(1,5) 和 if age >= 18，正是前两种。

六条语句速览

语句作用什么场景用它一句话记
if / elif / else从几条路里选一条走判断条件、分情况处理哪条符合走哪条
for把一串东西挨个走一遍次数或范围已知有多少个就转多少圈
while条件为真就一直转不知道要转几次条件不满足才停
break立刻跳出整个循环找到了、不用再找了任务完成，收工
continue跳过本轮，进入下一轮这一项不处理，处理下一项这个不要，下一个
pass占个位，什么都不做结构先写好，内容以后填先留空，别报错就行

图怎么看：三种路线的区别只在"箭头往哪拐"。顺序执行的箭头永远向下；分支的箭头在一个菱形处分岔，走哪条取决于条件；循环的箭头绕回了上方——那个向左绕回的箭头就是循环的本质。写循环时脑子里的画面应该是这条回路，而不是"重复写了很多行代码"。循环之所以存在，是因为它能用 3 行代码表达 100 万次重复。

逐个认识

1

if / elif / else：从几条路里选一条

重点记住两件事：从上往下判断，命中第一条就收工；条件后面必须有冒号，下一行必须缩进。

这就是你 03.ipynb 里写的那段，把它跑一遍：

age = 12
if age >= 18:
    print("你已经成年了")
    print("你已经可以独立生活了")
elif age >= 13:
    print("你是青少年")
else:
    print("你还未成年")

# 输出：你还未成年
把 age 换成不同的值，看它走哪条路
age=20 -> 成年
age=15 -> 青少年
age=12 -> 未成年
顺序决定结果：如果把 if age >= 18 和 elif age >= 13 换个位置，age=20 会先命中 >= 13，输出"青少年"——分支是从上往下匹配的，第一条命中后，后面的全部跳过。所以写多个 elif 时，条件要从窄到宽（或从宽到窄）排好序，别写乱。另外 else 最多一个，elif 可以有很多个，都可以不写。
条件里能放什么

任何能算出真 / 假的东西都行：比较（> < == != >= <=）、in、and / or / not。有意思的是，Python 还允许直接塞一个值进去——下面这些都会被当成"假"：

print(bool(0), bool(""), bool([]), bool({}), bool(None))
# 输出：False False False False False

print(bool("0"), bool([0]), bool(-1))
# 输出：True True True   ← "0" 和 [0] 都非空，是真

所以写"列表不为空才处理"时，直接 if my_list: 就够了，不用写 if len(my_list) > 0:。

2

for 循环：把一串东西挨个走一遍

记住 range(5) 是 0 到 4，不含 5——这是初学者第一个大坑。

你在 03.ipynb 里写的 for i in range(1,5) 输出 1 2 3 4，因为 range 是"左闭右开"：包含起点，不包含终点。

range 的四种写法（全部实跑结果）
写法得到什么说明
range(5)[0, 1, 2, 3, 4]从 0 开始，共 5 个数
range(2, 6)[2, 3, 4, 5]从 2 到 5（不含 6）
range(1, 11, 3)[1, 4, 7, 10]第三个参数是步长
range(5, 0, -1)[5, 4, 3, 2, 1]步长为负就是倒数
for 不只能数数，它能遍历任何"一串东西"
for ch in "abc":            # 字符串：一个个字符
    print(ch, end="|")
# 输出：a|b|c|

for x in [10, 20, 30]:      # 列表：一个个元素
    print(x, end=" ")
# 输出：10 20 30

for k in {"姓名": "小明", "年龄": 19}:   # 字典：默认只给键
    print(k, end=" ")
# 输出：姓名 年龄

for k, v in info.items():   # 要键和值就加 .items()
    print(f"{k}={v}", end="  ")
# 输出：姓名=小明  年龄=19
遍历字典别踩坑：直接 for x in 字典 拿到的是键，不是值。想同时要键和值就写 for k, v in 字典.items()；只要值就用 字典.values()。
3

while 循环：条件为真就一直转

记住循环体里必须有东西能让条件趋向结束，否则就是死循环。

什么时候用 while 而不是 for？当你不确定要转几次时。比如"一直问用户输入，直到他输入 q 为止"。确定次数的（遍历列表、跑 100 次）用 for 更清楚。

count = 3
while count > 0:
    print("倒计时", count)
    count -= 1        # ← 这行是关键，少了它永远转不完
print("发射！")

# 输出：
# 倒计时 3
# 倒计时 2
# 倒计时 1
# 发射！
死循环怎么来的：如果把 count -= 1 删掉，count 永远是 3，条件永远成立，程序会一直打印"倒计时 3"——这就是死循环。在 VS Code 里按 Ctrl+C（notebook 里点 ■ 停止）就能中断。写 while 时先问自己：这个条件最终会变假吗？是什么让它变假的？
4

break / continue / pass：循环里的三个"开关"

三个词都只作用于循环，但做的事完全不同，别混。
for i in range(1, 10):
    if i == 5:
        break          # 整个循环直接结束
    print(i, end=" ")
# 输出：1 2 3 4      ← 到 5 就彻底停了

for i in range(1, 6):
    if i % 2 == 0:
        continue       # 只跳过这一轮，继续下一轮
    print(i, end=" ")
# 输出：1 3 5        ← 偶数被跳过，奇数照常

for i in range(3):
    if i == 1:
        pass           # 什么都不做（但语法上必须有东西占位）
    else:
        print("处理", i)
# 输出：处理 0 / 处理 2   ← 不报错，i==1 时安静跳过
语句效果典型场景
break跳出整个循环，后面的轮次不再执行找到了目标、密码试错次数用完
continue结束本轮，直接开始下一轮跳过无效数据（空行、负数）
pass占位，什么都不做结构先写出来，细节以后再填
顺带一个冷门但好用的语法：for-else

for 后面可以跟一个 else，循环正常走完才执行；如果中途被 break 了，else 就不执行。可以拿来写"找遍了都没找到"这种逻辑：

for i in range(3):
    print(i, end=" ")
else:
    print("<- 正常结束走 else")
# 输出：0 1 2 <- 正常结束走 else

for i in range(5):
    if i == 2:
        break
else:
    print("这行不会打印（因为被 break 了）")
# 输出：（无）
5

嵌套循环：循环里面还有循环

记住执行顺序：内层跑完一整圈，外层才动一步。
for i in range(1, 4):        # 外层：i = 1, 2, 3
    for j in range(1, i + 1):    # 内层：每次都从 1 数到 i
        print(f"{j}x{i}={i*j}", end="  ")
    print()                   # 内层跑完，换行

# 输出：
# 1x1=1
# 1x2=2  2x2=4
# 1x3=3  2x3=6  3x3=9

九九乘法表就是这么来的。注意 print() 的位置——它在外层循环里、内层循环外，所以每一行打印完才换行。

别嵌套太深：三层以上就该考虑拆成函数了（第 2 次课会学），否则代码会变得很难读。还有个小工具：print(..., end=" ") 里的 end 能把默认的换行改成空格，打印表格时很有用。

拿它们干活：四个真实场景

场景 A：统计成绩——for + 条件 + 累加
scores = [88, 45, 92, 60, 73]
total = 0
passed = 0
for s in scores:
    total += s
    if s >= 60:
        passed += 1
print("总分", total, "平均", total / len(scores), "及格人数", passed)
# 输出：总分 358 平均 71.6 及格人数 4

这就是"累加器"模式：先准备一个 0，循环里往里加。数据统计十有八九都是这个套路——求和、计数、找最大，全靠"循环 + 一个变量记着结果"。

场景 B：猜数字——while True + break
target = 7
guesses = [3, 9, 7]          # 真实程序里这里换成 input()
for g in guesses:
    if g > target:
        print(f"猜 {g}：大了")
    elif g < target:
        print(f"猜 {g}：小了")
    else:
        print(f"猜 {g}：对了！")
        break                 # 猜中就收工，不再继续

# 输出：
# 猜 3：小了
# 猜 9：大了
# 猜 7：对了！

注意到没：break 让程序在"任务完成"的那一刻停下来。如果不用 break，猜中之后还会继续处理后面的猜测，逻辑就错了。

场景 C：找最大值——自己写一遍比背 max() 有用
nums = [88, 45, 92, 60, 73]
biggest = nums[0]            # 先假设第一个最大
for n in nums:
    if n > biggest:          # 遇到更大的就更新
        biggest = n
print("最大：", biggest, "| 对照 max()：", max(nums))
# 输出：最大： 92 | 对照 max()： 92

"先假设第一个，再逐个挑战"是寻找类算法的通用思路。想清楚这个，以后学排序、找极值都不陌生。

易混辨析

容易混的一对区别怎么记
for / while for 用于"有一串东西要挨个处理"（次数/范围已知）；while 用于"条件不满足才停"（次数未知） 能数清用 for，数不清用 while
break / continue break 结束整个循环；continue 只跳过本轮 break = 退学，continue = 请假一节课
range(5) / range(1,5) 前者的 5 是"个数"，后者两个数都是"边界"，且右边界取不到 一个参数 = 从 0 数几个；两个参数 = 左闭右开
if x == 1 / if x = 1 前者是比较，后者是赋值，运行会直接报 SyntaxError: invalid syntax 比较用两个等号，永远
for i in 5 / for i in range(5) 数字不能被遍历，前者报 TypeError: 'int' object is not iterable 想数数就得套 range
另外三个高频报错，记住长相就不会慌：
· SyntaxError: expected ':' → 条件 / 循环那一行的末尾忘了冒号（你 04.ipynb 里的 def 取名(姓,名) 就是这个问题）
· IndentationError: expected an indented block after 'if' statement on line 2 → if 下面那行没缩进
· IndentationError: unexpected indent → 缩进多了，或者该对齐的没对齐（Python 靠缩进划分代码块，4 个空格是约定；同一块里千万别有的行用 Tab、有的行用空格）

练习

别急着看答案，先自己写。写完对着答案比——重点看"我为什么没想到那一步"，而不是"我的能不能跑"。

1. 打印 1~100 中所有 3 的倍数 
for i in range(1, 101):
    if i % 3 == 0:
        print(i, end=" ")
# 输出：3 6 9 12 15 18 ... 93 96 99，共 33 个

要点：% 取余，能整除就是 0；范围要写到 101 才能包含 100，这就是"左闭右开"的直接体现。

2. 输入成绩，打印等级：90 以上 A，80 以上 B，60 以上 C，其余 D 
score = 85
if score >= 90:
    g = "A"
elif score >= 80:
    g = "B"
elif score >= 60:
    g = "C"
else:
    g = "D"
print(g)

# 实跑：95 -> A    85 -> B    72 -> C    58 -> D

要点：不用写成 if 80 <= score < 90（虽然 Python 支持），因为 elif 天然就排除了上面的区间——能走到 elif score >= 80 时，成绩必然已经小于 90 了。这是 if/elif 最省事的地方。

3. 用 while 循环算 1+2+3+...+100 
i = 1
total = 0
while i <= 100:
    total += i
    i += 1
print("结果：", total)
# 输出：结果： 5050

要点：两个变量分工明确——i 管"数到哪了"，total 管"攒了多少"。i += 1 是让循环能结束的关键。
对照思考：这题用 for 写更短：sum(range(1, 101))，一行搞定。但手写一遍 while 才能理解"累加"到底在做什么。

4. 猜数字游戏：最多猜 3 次，猜中提前结束，都没中就说答案 
target = 7
for times in range(1, 4):
    guess = int(input("猜一个数："))     # 实际用输入
    if guess == target:
        print(f"猜对了，你用了 {times} 次")
        break
    elif guess > target:
        print("太大了")
    else:
        print("太小了")
else:
    print("三次都没猜中，答案是", target)

# 模拟猜 3、9、7 的实跑输出：
# 第1次 猜3：太小
# 第2次 猜9：太大
# 第3次 猜7：猜对了，你用了3次

要点：这是"for + break + else"的经典组合——猜中就走 break（不执行 else），三次都没中循环正常结束，才执行 else 提示答案。int(input(...)) 是把输入的文字转成整数，不转的话"7"和 7 永远不相等。

5. 找出列表里的最大值（不许用 max） 
nums = [88, 45, 92, 60, 73]
biggest = nums[0]
for n in nums:
    if n > biggest:
        biggest = n
print("最大：", biggest)
# 输出：最大： 92（与 max(nums) 结果一致）

要点：biggest = nums[0] 不能写成 biggest = 0——如果列表里全是负数，从 0 开始就错了。"用数据自己的第一个值做起点"是个值得记住的习惯。

自检清单

能对着下面每条说清"是什么、什么时候用"，这节就算过关了：

  1. 能说清 if / elif / else 的判断顺序，并知道多个条件时为什么要注意排列顺序
  2. 记得 range(5) 是 0~4，且能说出三种 range 写法的区别
  3. 能判断什么时候该用 for、什么时候该用 while
  4. 知道 while 写错会死循环，以及怎么中断（Ctrl+C）
  5. 能准确区分 break 和 continue 的作用范围
  6. 能自己写出"循环 + 累加"来求总数、平均值、最大值
  7. 看到 SyntaxError / IndentationError 时，知道先去查冒号和缩进
  8. 能独立写出猜数字游戏，并解释为什么猜中时要 break
通关标志：不看答案，独立写出猜数字游戏（限次数 + 猜中提前结束 + 都没中给答案），并跑通。能做到，说明你已经掌握了循环、分支和跳转的配合——这正是第 1 次课最核心的一关。
